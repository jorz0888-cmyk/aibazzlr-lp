07 / FAQ

よくある質問

Q. 本当に自動で投稿されるのですか？
はい。初期設定を済ませれば、AIが毎日決まった時間に投稿内容を生成し、各SNSへ自動で配信します。承認制モードでは公開前に内容をチェックでき、完全自動モードでは一切の手間なく運用できます。
Q. AIが生成した文章はどれくらい自然ですか？
日本語に最適化された独自モデルを採用しています。過去の投稿からあなたの口調・語彙・絵文字傾向まで学習するため、使い込むほど"あなたらしい"文章になります。
Q. 解約はいつでもできますか？
はい、マイページから1クリックでいつでも解約可能です。違約金や最低契約期間はありません。Beta期間中の招待ユーザーには正式ローンチ前まで料金は発生しません。
Q. アカウント凍結のリスクはありませんか？
各SNSの公式APIを利用した正規連携のみを行います。スパム的な大量投稿はシステムで制限しており、通常運用でリスクが生じることはありません。
Q. どんな業種でも使えますか？
飲食・美容・IT・士業・EC・インフルエンサーなど、幅広い業種でご利用いただいています。業種ごとに投稿パターンをチューニングしているため、初期設定時に選ぶだけで最適化されます。
Q. 写真は何枚までアップロードできますか？
写真のアップロードは どのプランも無制限 です。お店の料理写真、店内写真、スタッフ写真などを自由にアップロードでき、AI が投稿に合うものを自動で選んで添付します。

各プランの「AI画像生成 月20枚」などの上限は、AI に 新しく画像を生成させる 場合にのみ適用されます。ご自身でアップロードした写真は、この枠を消費しません。
Q. X の「自動アカウントラベル」は設定が必要ですか？
必須ではありませんが、X 公式の推奨事項として設定をおすすめします。設定方法は X アプリの「設定とプライバシー → アカウント → 自動化」から「自動アカウント」をオンにし、管理者の @ID を入力します。詳細は X 公式ヘルプ をご覧ください。なお、新規 X アカウントや API 投稿に不安がある方は、AIBazzlr の コピペ投稿モード をご利用いただければ X API を使わないため、ラベル設定は不要です。
Q. サポート体制はどうなっていますか？
平日10:00-19:00のチャットサポートに対応。日本製サービスのため、すべて日本語で丁寧にご案内します。
